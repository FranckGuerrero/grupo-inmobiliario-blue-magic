## Reglas para reemplazar imágenes

1. Mantener formato WebP.
2. Usar nombres en minúsculas, sin espacios, tildes ni caracteres especiales.
3. No incluir datos personales, placas, documentos ni direcciones exactas visibles.
4. Mantener una imagen completa y una miniatura para cada propiedad o artículo.
5. Evitar ampliar artificialmente fotografías pequeñas.
6. Eliminar metadatos EXIF antes de publicar.
